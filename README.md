# Dron4k

Marketing/e-commerce site for a Ukrainian FPV/BPЛА drone school: pilot and drone-engineer courses, drone sales, and company info. Built with Next.js 14 (App Router) and TypeScript.

## Getting started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000).

```bash
npm run lint    # ESLint (airbnb config)
npm run build   # production build
npm run start   # serve the production build
```

### Environment variables

| Variable | Purpose | Default |
|---|---|---|
| `NEXT_PUBLIC_SITE_URL` | Absolute site URL used for `metadataBase`, Open Graph images, `robots.ts`, and `sitemap.ts`. **Set this to the real production domain before deploying** — it currently falls back to a placeholder. | `https://dron4k.example.com` |

## Routes

| Path | Page |
|---|---|
| `/` | Home — hero, three-pillar bento grid, social proof + contact form |
| `/about` | Company story and vision |
| `/courses` | The two courses (operator / engineer), each a `CourseCard` |
| `/store` | Drone listings, each a `StoreCard` |
| `/team` | Team/instructors blurb |
| `/policy` | Privacy policy (generic template — not legal advice) |
| `/robots.txt`, `/sitemap.xml` | Generated by `src/app/robots.ts` / `sitemap.ts` |

All copy and business data (course prices/specs, product listings, contact info) lives in `src/utils/constants.ts` — edit there rather than in the page components.

## Design system — "Neon Velocity"

The site follows a black/neon-lime, glassmorphic visual language:

- **Colors**: background `#050505`, accent lime `#BFFF00` (Tailwind: `bg-neon`/`text-neon`), everything else driven by the shadcn-style CSS variables in `src/app/globals.css` (`--background`, `--card`, `--primary`, etc.) — retheme the site by editing those variables and `tailwind.config.ts`'s `colors`/`fontFamily`/`boxShadow` extensions.
- **Type**: `font-heading` (Plus Jakarta Sans 800, uppercase, tight tracking) for headlines, `font-techmono` (JetBrains Mono, uppercase, wide tracking) for labels/eyebrows/nav, default `Inter` for body copy. All three are loaded via `next/font/google` in `src/app/layout.tsx` with Cyrillic subsets enabled (Ukrainian copy).
- **Effects**: `NoiseOverlay` (fixed fractal-noise texture), the `.glass` utility (blurred translucent panel), `ScrollReveal` (fade/translate-up on scroll into view via `IntersectionObserver`), and the `laser-sweep`/`reveal-up` keyframes in `tailwind.config.ts`.

### Key shared components (`src/components/`)

- **`Button`** — the single component behind every CTA on the site. `variant="laser"` (solid lime, sweeping hover light) or `variant="ghost-glass"` (glass outline). Pass `href` and it renders an internal `Link`, an external `<a>`, or a `mailto:`/`tel:` link automatically; omit it for an `onClick` handler.
- **`ui/luminosity-card`** — the bento/feature card used on Home, About, Courses, and Store. Tracks the cursor to drive a radial-gradient glow; `size="bento"` (min-height 450px) or `size="compact"`.
- **`ui/card`, `ui/badge`** — plain shadcn/ui primitives (no Radix dependency), themed via the CSS variables above.
- **`MobileBottomNav`** — fixed glass pill nav shown below the `sm` breakpoint (Home/About/Courses/Store); the header's own nav links are desktop-only.
- **`ScrollReveal`**, **`NoiseOverlay`**, **`ui/avatar-stack`**, **`ContactPill`** — supporting pieces described above. `ContactPill` has no backend to submit to (nothing on this site does); it opens a pre-filled `mailto:` with whatever the visitor typed.

### Known placeholders / things to revisit before going live

- `NEXT_PUBLIC_SITE_URL` (see above).
- The ZSU donation badge (`ZSUHelp`, shown in the footer) links to a well-known charity (savelife.in.ua) as a reasonable default — swap it if there's a specific link intended.
- `companyInSocial` in `constants.ts` points at the generic Instagram/Telegram/Facebook home pages, not real company profiles.
- The four products on `/store` are identical placeholder listings (`sellCards` in `constants.ts`) — replace with real inventory.
- `/policy` is generic boilerplate, not reviewed legal text.

## Project structure

```
src/
  app/                # routes (Next.js App Router) — page.tsx + co-located *.module.css
  components/
    ui/                # shadcn/ui-style primitives (card, badge, luminosity-card, avatar-stack)
    <Component>/       # one folder per component: Component.tsx + Component.module.css
  utils/
    constants.ts       # all site copy/business data
    cn.ts               # shadcn's className-merge helper (clsx + tailwind-merge)
public/assets/images/  # static images referenced via the `@images/*` path alias
```

Path aliases (see `tsconfig.json`): `@components/*` → `src/components/*`, `@utils/*` → `src/utils/*`, `@images/*` → `public/assets/images/*`, `@*` → `src/*`.

## Tech stack

Next.js 14 (App Router) · TypeScript · Tailwind CSS · shadcn/ui-style primitives (`class-variance-authority`, `clsx`, `tailwind-merge`, no Radix) · `react-icons`.
